КАК ДА ГО ПУБЛИКУВАШ В GITHUB PAGES
1. На github.com: New repository -> име напр. "vlakove" -> Public -> Create.
2. Add file -> Upload files -> качи ВСИЧКИ файлове от тази папка (не архива) -> Commit.
3. Settings -> Pages -> Source: "Deploy from a branch", Branch: main, папка /(root) -> Save.
4. След 1-2 минути адресът е https://<потребител>.github.io/vlakove/
5. На телефона отвори адреса в Chrome -> менюто ⋮ -> "Install app" / "Add to Home screen".
